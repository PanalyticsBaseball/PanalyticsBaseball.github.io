## Project overview

This was Gabriel's first project using R Shiny. It was built as a hands-on learning experience in turning R analysis into an interactive web application, including interface structure, connections to R code, interactive outputs, and online deployment.

## Role in the portfolio

The application documents the starting point of Gabriel's interactive data work and provides the foundation for more advanced baseball applications.
