## Project overview

The Miami Marlins Prospect Report is an interactive R Shiny application focused on organizing and presenting prospect information. It transforms baseball data into an accessible report for exploring player performance and reviewing the organization's prospect pool through a web interface.

## Objective

Combine data analysis, visualization, and interactive reporting so that prospect information can be explored and communicated in a concise format.
